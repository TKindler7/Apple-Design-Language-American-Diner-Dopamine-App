# Project Rules

## Source control

- Keep all project work versioned in Git and commit completed changes before deployment.
- Push commits to the project's GitHub repository. Do not force-push unless explicitly requested.

## Deployment

- Deploy this app with Vercel.
- Do not use ChatGPT Sites for hosting or publishing this project.

## Delivery checks

- Before a production deployment, run the relevant build and test checks.
- Keep credentials and local environment files out of version control.
