# Pennyglass Diner

A fictional American diner experience about the pleasure of imagining an order. It uses original menu items and original SVG illustrations, with a spacious, minimal visual style.

**Design claim:** My site makes people feel the satisfying anticipation of a diner meal when they build their perfect order.

## CP1 starter cart

The menu has three items. Visitors can add, increase, decrease, or remove items; the cart shows a running total. It saves to this browser's `localStorage` after every change and loads again on refresh. There is no checkout, account, payment, or delivery.

To run locally, serve this folder with any static server, for example `python3 -m http.server 4173`, then visit `http://localhost:4173`. Run `npm test` for cart behavior checks and `npm run build` to check local asset references. Vercel can publish the folder as a static site without a build command.
